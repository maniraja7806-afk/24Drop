# 24Drop

24Drop is a modern, real-time communication platform designed to provide a seamless chatting and global feed experience. It allows users to engage in private chats, share thoughts on a global feed, and communicate with rich media including images and audio.

## Key Features
- **Real-Time Chat:** Instant messaging with typing indicators, reactions, and pinned messages.
- **Global Public Feed:** Share thoughts and media with everyone, featuring auto-expiring posts.
- **Rich Media Support:** Send images, voice recordings, and files.
- **Modern UI:** Clean, responsive interface with smooth animations and transitions.

## Technologies Used
- **Frontend:** React.js, Vite, TypeScript, Tailwind CSS, Framer Motion
- **Backend:** Node.js, Express.js, TypeScript
- **Database:** SQLite (Better-SQLite3)
- **Real-time:** Socket.io
- **Storage:** Cloudinary integration for media assets
